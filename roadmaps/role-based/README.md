## What these roadmaps cover

Each guide follows the same rhythm:

1. **Foundations** — the concepts and tools you need before the work gets complex.
2. **Core practice** — the skills you use every week in the role.
3. **Production skills** — reliability, testing, security, and collaboration.
4. **Proof of skill** — a portfolio-ready project and interview talking points.

Choose a role to see the full sequence. Related skill and project pages are linked at the bottom of each roadmap.
