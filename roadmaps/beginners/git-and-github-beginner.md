# Git and GitHub Beginner

Save your work without fear, understand what a commit means, and share a project on GitHub.

[← Beginner roadmaps](README.md) | [All roadmaps](../README.md)

## Start here

- [ ] Install Git and set your name and email
- [ ] Create a project folder and make your first commit
- [ ] Create a GitHub repository and push the project
- [ ] Change one file and view the diff before committing

## Learning stages

### 1. Git as a safety net

- The difference between Git and GitHub
- The working tree, staged changes, and commits
- `git status` and `git diff`
- Adding files and making a commit
- Writing a useful commit message
- Undoing an uncommitted change

**Build:** track a small text project with at least five focused commits.

### 2. A readable history

- One logical change per commit
- Ignoring generated and personal files
- Checking status before every commit
- Restoring one file instead of everything
- Reading the log and understanding what changed

**Build:** improve a messy set of changes by splitting it into a clear, explainable history.

### 3. Git and GitHub together

- Remote repositories and the push/pull flow
- Cloning an existing project
- Comparing a local branch with its remote
- Creating a branch for a change
- Opening a pull request and requesting review

**Build:** submit one small change through a branch and pull request.

### 4. Collaboration basics

- What a merge conflict is
- Reading conflict markers and choosing the correct result
- Updating a branch before a pull request
- Reviewing a teammate’s change
- Reporting a problem with an issue

**Build:** simulate a conflict with two branches and resolve it deliberately.

## Definition of done

You can save work in small commits, recover from simple mistakes, push to GitHub, and explain the difference between a local change and a published one.

## FAQ

### Do I need the command line?

It is the most reliable way to learn the state model, but a GUI client is fine once you understand the concepts. Avoid running commands you cannot explain.
