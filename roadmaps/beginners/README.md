# Absolute Beginner Roadmaps

Start with a small, visible result. The goal is not to memorize everything; it is to learn how to turn a problem into working code.

[← All roadmaps](../README.md)

- [Frontend beginner](frontend-beginner.md) — build and publish your first web page
- [Git and GitHub beginner](git-and-github-beginner.md) — save your work and share a project

## Getting unstuck

1. Reproduce the problem in the smallest example you can.
2. Read the complete error message and identify the line that failed.
3. Check one credible source before trying a change.
4. Change one thing at a time.
5. Write down what worked; it is now part of your toolkit.
