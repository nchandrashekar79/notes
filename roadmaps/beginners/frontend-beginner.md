# Frontend Beginner

Go from no programming experience to a small web application you can publish.

[← Beginner roadmaps](README.md) | [All roadmaps](../README.md)

## Start here

- [ ] Create an HTML file and open it in a browser
- [ ] Make one thing appear, change, or respond to a click
- [ ] Add a short README describing what the page does
- [ ] Share it with a friend and ask what confused them

## Learning stages

### 1. How the web works

- Browser, server, URL, and request
- HTML for content and structure
- CSS for presentation
- JavaScript for behavior
- Using browser developer tools

**Build:** a single-page introduction with headings, links, an image, and a short list.

### 2. Structure and styling

- Semantic elements: `header`, `main`, `section`, `footer`
- Headings in a logical order
- The box model, spacing, and alignment
- Colors, typography, and readable contrast
- Flexbox and a simple responsive layout

**Build:** a responsive page that remains readable at phone and desktop widths.

### 3. Interaction

- Variables, functions, and conditions
- Selecting elements in the page
- Responding to button clicks and form submissions
- Showing and hiding content
- Reading the console when something fails

**Build:** a small to-do or notes page that adds, completes, and removes items.

### 4. Save and share

- The basic Git workflow: status, add, commit
- Creating a GitHub repository
- Publishing a static page with GitHub Pages
- Writing a README with a project screenshot

**Build:** publish your project and add the live link to your README.

## Definition of done

You can build a small interactive page, debug it with developer tools, track it with Git, and publish it with a link another person can open.

## FAQ

### What should I build first?

A page about something you already know. A personal introduction, a study guide, or a page for a hobby gives you real content and makes the result easier to share.
