# Learning Resources

Use a small set of trusted references. A plan you can follow beats a long list of links.

[← All roadmaps](../README.md)

## Official documentation

- [MDN Web Docs](https://developer.mozilla.org/) — HTML, CSS, JavaScript, and browser APIs
- [Python documentation](https://docs.python.org/3/) — language reference and standard library
- [Git documentation](https://git-scm.com/doc) — reference and Pro Git book
- [GitHub Docs](https://docs.github.com/) — repositories, collaboration, and Pages

## Practice

- [Exercism](https://exercism.org/) — guided exercises with human feedback
- [freeCodeCamp](https://www.freecodecamp.org/) — project-based web development curriculum
- [Advent of Code](https://adventofcode.com/) — annual, language-agnostic problem solving

## Deeper reading

- *The Pragmatic Programmer* by David Thomas and Andrew Hunt
- *Designing Data-Intensive Applications* by Martin Kleppmann
- *Refactoring* by Martin Fowler

## Validate a resource

Before committing time to a tutorial or course, check whether it is current, gives you working code to modify, and explains the trade-offs rather than only the happy path.
