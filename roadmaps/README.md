## How to use these roadmaps

1. **Choose one track.** Pick a role or skill that supports a project you want to build.
2. **Study in order.** Each page lists stages; complete the “Start here” checklist before moving on.
3. **Build after each stage.** A small finished project teaches more than an unfinished tutorial.
4. **Record evidence.** Keep notes, screenshots, tests, and a short retrospective.
5. **Revisit quarterly.** Update the roadmap as your goals and the technology change.

These guides are starting points, not complete curricula. Prioritize understanding, working software, and feedback from other developers.
