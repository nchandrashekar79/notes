# Python

Learn readable, testable Python and use it to solve practical data and application problems.

[← Skill based roadmaps](README.md) | [All roadmaps](../README.md)

## Start here

- [ ] Run a Python script in a virtual environment
- [ ] Write and use functions with clear names
- [ ] Read and process a CSV or JSON file
- [ ] Add basic tests for the processing logic

## Learning stages

### 1. Language fundamentals

- Values, variables, expressions, and control flow
- Lists, tuples, dictionaries, and sets
- Functions, default arguments, and return values
- Modules, packages, and virtual environments
- Exceptions and context managers
- Reading and writing files

**Build:** a command-line expense tracker that saves records and reports totals by category.

### 2. Object design and typing

- Classes, composition, and data classes
- Iterators and generators
- Type hints and practical static checking
- Protocol-based interfaces where appropriate
- Date and time handling

**Build:** a small library with typed input, validation, and tests.

### 3. Working with data

- CSV and JSON processing
- Tabular analysis with pandas or an equivalent library
- SQL queries and Python database clients
- Data cleaning and missing values
- Charts for communicating results

**Build:** a repeatable report that loads raw data, validates it, summarizes it, and exports a chart.

### 4. Web APIs and services

- HTTP clients and error handling
- A web framework such as FastAPI, Flask, or Django
- Request validation and structured responses
- Authentication and environment configuration
- Background tasks and scheduled jobs

**Build:** a documented API backed by a database with tests and a local setup guide.

### 5. Quality and delivery

- `pytest` with fixtures and focused test cases
- Linting and formatting
- Dependency locking and reproducible environments
- Packaging and command-line entry points
- Continuous integration and deployment
- Logging, metrics, and configuration management

**Build:** package your application, publish it to a repository, and automate its tests.

## Definition of done

You can structure a multi-module Python application, test its important behavior, connect it to a data store or API, and deploy it with a repeatable setup.
