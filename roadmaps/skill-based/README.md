## How to study a skill

Use a **learn → build → explain** loop:

- **Learn** the concept with one trusted reference.
- **Build** a small program that could not have been written without it.
- **Explain** the trade-offs and common mistakes in your own words.

Avoid collecting tutorials. Each stage below includes a concrete deliverable and a definition of done.
