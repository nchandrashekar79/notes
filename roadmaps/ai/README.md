# AI Roadmaps

Learn to build reliable products with foundation models. The focus is on systems, evaluation, and responsible delivery—not training a model from scratch.

[← All roadmaps](../README.md)

- [Prompt engineering](prompt-engineering.md) — design, test, and maintain reliable instructions
- [AI agents](ai-agents.md) — combine models, tools, memory, and guardrails

## Prerequisites

Comfortable with at least one programming language and HTTP APIs. The [Python roadmap](../skill-based/python.md) is a useful starting point for many AI projects.

## Keep these concerns visible

- **Evaluation** — define what “good” means and measure it.
- **Safety** — limit the agent’s authority and protect private data.
- **Cost and latency** — track them as product requirements.
- **Observability** — record inputs, retrieval, tool calls, and outputs.
