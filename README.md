## Publish with GitHub Pages

This repository is a static Jekyll site. GitHub Pages can build it directly; no local build or deployment workflow is required.

1. Push the repository to GitHub with this content on the `master` branch.
2. In the repository, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select branch **`master`** and folder **`/ (root)`**, then save.
5. Wait for GitHub to report the deployment site address.

The site will appear at:

```text
https://<your-github-user>.github.io/<repository-name>/
```

The Jekyll configuration is in [`_config.yml`](_config.yml). The published landing page is [`index.md`](index.md). Every roadmap page is written in Markdown under [`roadmaps/`](roadmaps/).
